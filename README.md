# AUTISOLVE

AI-powered autism support application for parents.

AUTISOLVE is a Flutter-based application designed to help parents access AI-assisted guidance, child activity tracking, and support resources.

## Features

- AI-powered chat support for parents
- Child profile management
- Activities and progress tracking
- Report upload and progress reporting
- Image and document-based assistance
- Web search support

## Technology Stack

- Flutter and Dart
- Firebase
- Cloudflare Workers AI

## Project Setup

1. Install Flutter and configure the Flutter SDK.
2. Clone the repository.
3. Open the project directory in a terminal.
4. Run `flutter pub get`.
5. Configure the required Firebase settings and backend environment variables.
6. Run the application using `flutter run`.

## Project Purpose

AUTISOLVE aims to provide parents with accessible digital support for understanding their child's needs and tracking activities and progress.
